## English

First packaged release of **Taskbar Thermals Fix** for Windows 11 x64.

- Keeps the temperature panel visible with Start open and after **Start → taskbar click** using a local Windhawk compatibility mod.
- English/Polish installer and uninstaller, with backup of any existing copy of this mod.
- Optional screen capture compatibility patch for the official .NET-dependent Taskbar Thermals 1.1.0 executable.
- Preserves settings, history, logs, startup configuration and unrelated Windhawk mods.
- MIT-licensed fix and installer; upstream application and dependency notices included.

**Download:** `TaskbarThermalsFix-1.0.0-Setup.exe`. Install standard x64 Windhawk and Taskbar Thermals first. The standard installer selection adds only the Start menu fix. The optional application component does not support the standalone executable or unknown versions.

Initial runtime verification: Windows 11 25H2 build 26200.9711, Windhawk 1.7.3. Actual reboot validation is pending. Private Windows interfaces may require adjustments after future system updates.

## Polski

Pierwsze wydanie instalacyjne **Taskbar Thermals Fix** dla Windows 11 x64.

- Panel temperatur pozostaje widoczny przy otwartym Starcie i po sekwencji **Start → kliknięcie paska**, dzięki lokalnemu modułowi Windhawk.
- Instalator i deinstalator ENG/PL z kopią wcześniejszej wersji tego modułu.
- Opcjonalna poprawka zrzutów ekranu dla oficjalnego pliku Taskbar Thermals 1.1.0 wymagającego .NET.
- Zachowane ustawienia, historia, logi, konfiguracja autostartu i pozostałe mody Windhawk.
- Poprawka i instalator na licencji MIT; dołączone informacje licencyjne oryginalnej aplikacji i zależności.

**Pobierz:** `TaskbarThermalsFix-1.0.0-Setup.exe`. Najpierw zainstaluj standardowy Windhawk x64 oraz Taskbar Thermals. Instalacja standardowa dodaje tylko poprawkę Startu. Opcjonalny składnik aplikacji nie obsługuje wariantu standalone ani nieznanych wersji.

Początkowa weryfikacja działania: Windows 11 25H2, kompilacja 26200.9711, Windhawk 1.7.3. Test rzeczywistego restartu pozostaje do wykonania. Prywatne interfejsy Windows mogą wymagać zmian po przyszłych aktualizacjach systemu.
